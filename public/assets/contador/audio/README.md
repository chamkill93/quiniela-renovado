sirena-quinie.wav es la sirena de cinco segundos aprobada para el contador. El botón
"Activar sirena horaria" habilita su reproducción después de cada hora transcurrida;
el primer sonido ocurre una hora después de activar el control. Se solicita un clic
porque los navegadores bloquean el audio automático hasta que el visitante interactúa.

El ambiente opcional de celebración puede agregarse como celebracion.mp3. La página
detecta el archivo y muestra un control accesible para reproducirlo o pausarlo.
