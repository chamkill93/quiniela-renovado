# Branding quinie.LA

quinie.LA es un subproducto de Aposta.LA. Debe sentirse parte de la misma familia, pero con identidad propia de Quiniela.

## Reglas visuales no negociables
- Todos los contenedores y controles deben ser redondeados. Evitar esquinas duras.
- CTA principal siempre rojo de marca.
- Dark como tema principal. Light debe ser gris/calido, nunca blanco puro.
- No usar el texto `ECOSISTEMA .LA`.
- No usar etiquetas `NUEVO` en Instantaneas.
- El selector de tema y el sonido son icon-only.
- El saldo vive en topbar/cabecera; no agregar carga de saldo abajo del sidebar.
- Sidebar: Inicio, Quinielas, Instantaneas, Reglas, Mis Jugadas, Resultados y Cuenta/Gestion segun rol.
- Instantaneas es el nombre exacto de la seccion.
- No usar emojis como iconografia final. Utilizar SVG del producto.
- No convertir el producto en una tragamonedas generica. Los rodillos son numericos y sirven para representar 001-999.

## Tipografia
No se entregan archivos de fuentes. Usar una pila web segura y de alta legibilidad. Base recomendada: `Inter, system-ui, sans-serif`. Para headings se puede evaluar una display sans compatible sin romper el branding.
