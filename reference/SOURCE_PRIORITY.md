# Prioridad de fuentes

## 1 - Fuente funcional obligatoria
`reference/original-v25/quinie_v25_SOURCE_OF_TRUTH.html`

Es la fuente de verdad para flujos, nombres, reglas visibles, tema claro/oscuro, navegacion, saldo superior, sonido, responsive, reglas, comprobantes, juegos tradicionales e Instantaneas. No se debe eliminar funcionalidad por simplificar la migracion.

## 2 - Reglas y arquitectura
`project-docs/`

Los documentos de producto amplían v25 con las 9 Instantáneas, seguridad, arquitectura y QA. Pueden agregar requisitos, pero no eliminar flujos existentes del HTML.

## 3 - Direccion visual
`public/assets/mockups/`

Los mockups definen el nivel de pulido deseado: contornos redondeados, iconografia propia, rodillos numericos premium, fichas y feedback. No deben usarse para inventar logica de negocio que contradiga al HTML.

## 4 - Marca madre Aposta.LA
`project-docs/APOSTA_LA_REFERENCE.md`

Usar Aposta.LA como referencia de familia visual, estructura legal y lenguaje de producto. No copiar texto regulatorio de apuestas deportivas como si aplicara automaticamente a Quiniela.

## 5 - Version Fernando Ribeiro
`reference/fernando-secondary/`

Solo es referencia secundaria para recursos, tratamiento visual, stack y componentes. Nunca puede reemplazar una regla o flujo del HTML v25. Si hay conflicto, gana el HTML v25.
